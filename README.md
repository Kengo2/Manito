# Manito Proformas

Prototipo de Manito: proformas profesionales desde el celular, en PDF, listas para enviar por WhatsApp.

- Página única (`index.html`), sin compilación: se publica tal cual en Vercel.
- Los datos del usuario, sus servicios frecuentes y el historial se guardan en el propio teléfono (localStorage).
- El PDF se genera en el navegador con jsPDF.
